# אגרות קודש – כ"ק אדמו"ר מנחם מענדל שניאורסאהן (28 כרכים)

כל מכתבי סדרת "אגרות קודש" של הרבי (כרכים א–כח), בטקסט מלא ובמבנה נוח לבניית מסד נתונים ומנוע חיפוש.

**מקור:** ספריית ליובאוויטש – https://chabadlibrary.org/books (ממשק `api/main?path=<id>`).
כל רשומה כוללת `url` שמוביל למכתב באתר המקור.

## סטטיסטיקה

* **11,062 מכתבים**: מספרים 1–10,972 ברצף מלא, בלי חוסרים, ועוד 90 מכתבים שמסומנים בכוכבית (כמו `קמא*`)
* **25,266 הערות שוליים** של העורכים
* שנה עברית מזוהה ב-10,791 מכתבים (97.5%), ותאריך לועזי ב-10,396 מכתבים
* טווח: תרפ"ח (1928) עד תשל"ד (1974)
* שפות: עברית ~9,660, אידיש ~1,395

## קבצים

| קובץ | תוכן |

| `igrot_kodesh.jsonl.gz` | **הקובץ הראשי.** שורה = מכתב (JSON), כולל טקסט מלא, מטא-דאטה והערות. |
| `igrot_kodesh_index.csv` | טבלת מטא-דאטה בלבד (בלי טקסט) – לפתיחה מהירה באקסל. |

## שדות של כל מכתב

| שדה | תיאור |
|---|---|
| `id` | מזהה המכתב באתר המקור (ייחודי) |
| `volume` / `volume_heb` | מספר הכרך (1–28) / באותיות (`יב`) |
| `letter_number` / `letter_number_heb` | מספר המכתב הרץ בסדרה (1–10,9xx) / כפי שמופיע (`ד'רמב`) |
| `date_raw` | שורת התאריך כפי שמופיעה במכתב (`ב"ה, כ"ג ניסן, תשט"ז`) |
| `date_editorial` | תאריך משוער של העורכים כשאין תאריך במכתב (`לפני ת"ש`) |
| `hebrew_day` / `hebrew_month` / `hebrew_year` | פירוק התאריך העברי (`23` / `ניסן` / `5716`) |
| `gregorian_date` | המרה לתאריך לועזי `YYYY-MM-DD` (או `YYYY-MM` כשהיום לא ידוע) |
| `city` | עיר הכתיבה (`ברוקלין.`) |
| `recipient` | שורת שם הנמען, מחולצת מהכתובת (ריק במכתבים שפורסמו בעילום שם) |
| `address` | פתיחת המכתב / הכתובת המלאה, שורה לכל שורה |
| `language` | `he` / `yi` / `en` / `ru` (זיהוי אוטומטי) |
| `body` | גוף המכתב – טקסט נקי, פסקאות מופרדות בשורה ריקה |
| `signature` | החתימה |
| `postscript` | טקסט שבא אחרי החתימה (הוספות, כתובת וכו') |
| `source_note` | הערת המקור של העורכים (`נדפסה ב...`, `מהעתקה`) |
| `notes` | רשימת הערות השוליים: `[{"term": "ברכות נח", "text": "..."}]` |
| `full_text` | כל המכתב ברצף (תאריך, כתובת, גוף, חתימה) – לחיפוש / תצוגה |
| `html` | ה-HTML המקורי מהאתר (שומר הדגשות ומבנה) |
| `prev_id` / `next_id` | המכתב הקודם / הבא |
| `url` | קישור למכתב באתר המקור |

### הערות על איכות הנתונים
* **תאריכים** – הפענוח אוטומטי. הוא מטפל בקיצורים (`מנ"א`, `אד"ר`, `מ"ח`), בשנים מקוצרות (`פ"ח` = תרפ"ח), בראשי חודשים ובחגים נפוצים (`ערה"ש`, `ער"ס` וכו'). תאריכים שנכתבו לפי פרשה (`עש"ק פ' פרה`) מקבלים שנה בלבד. השדה `date_raw` נשמר תמיד, כך שאפשר לתקן או לשפר.
* **`אדר`** סתם בשנה מעוברת מתפרש כאדר א'.
* **`recipient`** – זו השורה בכתובת שמכילה תואר כמו `שי'`, `שליט"א` או `נ"י`, ולא שם "מנורמל". הכתובת המלאה נמצאת ב-`address`.

## שימוש

```python
import gzip, json
letters = [json.loads(l) for l in gzip.open("data/igtotkodsh/igrot_kodesh.jsonl.gz", "rt", encoding="utf-8")]
```

בניית מסד SQLite עם חיפוש:
```bash
python3 scripts/igrot_kodesh/build_db.py          # -> data/igtotkodsh/igrot_kodesh.db
```
```sql
SELECT l.volume, l.letter_number_heb, l.date_raw, l.recipient
FROM letters_fts f JOIN letters l ON l.id = f.rowid
WHERE letters_fts MATCH 'מחנה ישראל' ORDER BY rank LIMIT 20;
```
באינדקס החיפוש הגרשיים בתוך מילים מוסרים (`שליט"א` → `שליטא`). צריך לנרמל את השאילתה באותה צורה (`normalize()` ב-`build_db.py`).

החיפוש הרגיל מתאים מילים שלמות, כך ש-`רוגוטשוב` לא ימצא את `מרוגוטשוב`. אפשר להשתמש בחיפוש קידומת (`רוגוטשוב*`). לחיפוש תת-מחרוזת מלא, כולל אותיות שימוש בתחילת מילה, בונים עם `--trigram`. הקובץ יוצא גדול יותר.
