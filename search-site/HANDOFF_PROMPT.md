# הודעת פתיחה לסשן חדש (שרת עם GPU)

מעתיקים את הטקסט שבתוך התיבה ומדביקים אותו כהודעה הראשונה בסשן החדש.

```
אנחנו ממשיכים פרויקט קיים: מנוע חיפוש לאגרות קודש של הרבי מליובאוויטש (11,062 אגרות, 28 כרכים).
הריפו: https://github.com/Mocoloco461/ChabadLab, ענף igrot-kodesh.

המטרה:
אתר חיפוש בעברית עם:
(1) חיפוש טקסט מדויק
(2) סינון לפי כרך, שנה, נמען וכו'
(3) חיפוש לפי משמעות (NLP)
(4) בהמשך: נושאים וקטגוריות
(5) בהמשך: סוכן AI שעונה על שאלות מתוך האגרות, עם הפניות למקור

שלבים 1–3 כבר בנויים בתיקייה search-site/. כרגע 76.8% הצלחה בסט הבדיקות ו-71.0% בסט האימות. היעד הוא 80% בשניהם.
עברנו לשרת הזה כי יש בו GPU: בשרת הקודם (CPU בלבד) מודל ההטמעה החזק (bge-m3) היה לוקח 6–10 שעות לבנייה.

לפני שאתה עושה משהו:
1. עשה checkout לענף igrot-kodesh.
2. קרא את search-site/NEXT_STEPS.md (הוראות הקמה + צעדים לפי סדר עדיפות).
3. קרא את WORKLOG.md בשורש הריפו (כל מה שנעשה, עם מספרים).
4. קרא את search-site/README.md.
5. סכם לי במשפטים ספורים מה הבנת ומה התוכנית, ואז התחל מ"הקמה בשרת החדש" ו"צעד A".

כללי עבודה:
- כל שינוי נמדד עם search-site/eval/run_eval.py על שני הסטים: הראשי וסט האימות (eval/holdout/).
- אסור לכוונן על סט האימות.
- אחרי כל שלב: קומיט + רשומה ב-WORKLOG.md (מה נעשה, hash של הקומיט, תועלת במספרים, הערות להמשך), ואז push לענף igrot-kodesh.
- אפשר להפעיל סוכנים קטנים יותר (Sonnet, Haiku) לבדיקות ולכתיבת מקרי בדיקה, כמו שנעשה בסבבים הקודמים.
- לפני הורדות גדולות: לבדוק מקום בדיסק (df -h). לא למחוק קבצים של המשתמש בלי אישור.
- שלב הקטגוריות ושלב סוכן ה-AI דורשים את אישורי ומפתח API (מוגדר כסוד בסביבה, לא בצ'אט). שאל אותי לפני שמתחילים אותם.
- תעדכן אותי בעברית פשוטה, ותשאל כשמשהו לא ברור.
```

## מה צריך לוודא לפני שמתחילים

* **הקוד נמצא ב-GitHub.** מריצים בשרת הישן: `cd /root/ChabadLab && git push -u origin igrot-kodesh`.
* **בשרת החדש יש:**
  * GPU (בודקים עם `nvidia-smi`)
  * גישה לאינטרנט, כדי להוריד מודלים מ-HuggingFace
  * לפחות 20GB פנויים בדיסק
